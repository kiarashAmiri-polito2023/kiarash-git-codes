# 1. Final Mission

Build a traceable, human-supervised, dual-source
Vision-Language-Action dataset for training QwenVLA to understand:

1. Vision: what the robot and laboratory cameras observed.
2. Language: what object, situation, risk and instruction describe it.
3. Action: what command should be issued and why.

Primary physical system:

- MiR mobile robot
- OptiTrack Motive / NatNet
- Multiple Motive cameras, currently at least Camera 1 and Camera 4
- SLAM/LiDAR and occupancy-map observations
- Python 3.10
- ROS Bridge is expected around 192.168.12.20:9090, but the exact
  robot connector must still be identified from source code

The final dataset is not a raw video dataset. Each training record must
preserve observation, language, action, confidence, provenance, timing,
coordinate frames and the reason behind the action.

---

# 2. Final Training Strategy

The final architecture is Dual-Source Redundant Training, not a simple
one-way Teacher-Student pipeline.

Both modalities are first-class training sources:

1. Motive ceiling-camera video with human-confirmed bounding boxes,
   Motive rigid-body identities and world coordinates.
2. SLAM/LiDAR map video with robot pose, clusters and human-confirmed
   obstacle identities.

The model must learn from both modalities in parallel. If the ceiling
camera is unavailable outside the laboratory, the trained system should
still operate from SLAM/LiDAR. If SLAM evidence is temporarily weak,
the Motive modality remains useful during development and validation.

---

# 3. Role of the Deep Learner

The Deep Learner is the Judgment Brain, not a side text generator.

It is responsible for:

1. Producing language instructions from object class, safety zone,
   approach speed, direction and confidence.
2. Determining or validating Action Ground Truth.
3. Weighting or quarantining uncertain samples.
4. Enriching samples using cross-session behavioral knowledge.

Raw pose is an outcome. Robot command/decision history is intent.

The final Action Ground Truth should combine:

- command history
- safety-controller overrides
- obstacle-avoidance decisions
- robot pose/outcome
- deep learner judgment
- human confirmation where needed

No visual annotator should invent Action Ground Truth merely from a
bounding box.

# 8. Motive/AVI Synchronization QA

For every camera:

1. Read AVI frame count.
2. Read AVI FPS.
3. Compute duration.
4. Read CSV first and last valid time/frame values.
5. Compute CSV duration.
6. Estimate camera-specific time offset.
7. Flag:
   - missing timestamps
   - non-monotonic timestamps
   - duplicated timestamps
   - duration mismatch
   - frame-rate mismatch
   - dropped-frame suspicion
   - impossible position jumps
   - zero placeholders
   - untracked intervals
8. Never silently force alignment.
9. Record the chosen alignment method and its confidence.

A single session CSV may align differently with Camera 1 and Camera 4.
Offsets must therefore be stored per video/camera.

# 9. Overlay and Data-Leakage QA

Potential issue:

Motive Object Mode AVI may include marker, skeleton, name or graphical
overlays.

If overlays are burned into the AVI, QwenVLA may learn laboratory-only
graphics rather than real scene appearance.

Policy:

- Prefer raw clean frames for training.
- Overlay video may be used as an annotation aid.
- Flag each video:
  - overlay_present
  - overlay_suspected
  - overlay_absent
  - unknown
- Automatic detection is advisory only.
- Preserve the original video.
- If necessary, create a derived cropped/masked copy.
- Record all transformations in the annotation manifest.
- Never replace the source AVI.

- duplicate/conflict suggestions
- quality flags
- autosave and completion state
- annotation-file path
- SHA-256 checksum
- representative examples

This prevents the comprehensive report from becoming millions of lines
while keeping every coordinate fully traceable.

Cross-source learning policy:

- Dynamic objects require temporal and trajectory evidence.
- No suggestion becomes permanent without human confirmation.
