## بخش ۱: خلاصه پروژه و اهداف

### هدف کلی
ساخت دیتاست Vision-Language-Action برای آموزش QwenVLA با استفاده از:
- **Vision:** دوربین‌های سقفی OptiTrack Motive + LiDAR/SLAM ربات MiR
- **Language:** Entity Registry + Taxonomy برای توصیف اشیاء
- **Action:** تاریخچه فرمان‌های ربات (/cmd_vel + /odom + safety events)

### معماری آموزشی
**Dual-Source Redundant Training** — هر دو منبع Motive و SLAM به‌صورت همزمان و مکمل

### کد خراب (قبل از فیکس)

```python
def try_connect(self):
    try:
        import roslibpy

    HAS_CMD_LOGGER = False
    except ImportError:
        print("[SLAM] WARNING: roslibpy not installed.")
        return False
```

## بخش ۳: ایجنت‌های جدید ساخته شده

### ۳.۱ mir_command_logger.py
**هدف:** ضبط Action Ground Truth از ربات MiR  
**داده‌های ضبط شده:**
- `/cmd_vel` — فرمان سرعت
- `/odom` — سرعت واقعی (~۴۰ Hz)
- `/joystick_vel` — override دستی
- `/battery_state` — وضعیت باتری
- REST API `/status` — وضعیت کلی ربات

**تشخیص خودکار:** sudden_stop, manual_override

### ۳.۲ entity_registry.py
**هدف:** گروه‌بندی چند marker به یک entity واقعی  
**نتیجه فعلی:**
```
ENT-16E62CA238: person_kiarash (human, dynamic)
  markers: [kiarash_leftwrist, kiarash_RightWrist]
  status: PENDING

ENT-F63F0E4AD9: kia hat 002 (human, dynamic)  
  markers: [kia hat 002]
  status: PENDING
```

### ۳.۳ slam_auto_namer.py
**هدف:** انتساب نام entity به کلاسترهای SLAM بر اساس نزدیکی مکانی  
**روش:** فاصله اقلیدسی < ۰.۵ متر

### ۳.۴ cvat_prepopulator.py
**هدف:** تولید فایل CVAT XML با نام‌ها و bbox‌های پیشنهادی  
**خروجی:** `sessions/<session>/cvat_prepopulated/<session>_prepopulated.xml`

### ۳.۵ robot_data_analyzer.py
**هدف:** تحلیل رفتار ربات از داده‌های ضبط شده  
**خروجی:** action_summary, safety_summary, movement_patterns

### ۳.۶ video_quality_agent.py
**هدف:** بررسی ۱۵ فاکتور کیفیت ویدیو بر اساس استانداردهای صنعتی  
**استانداردها:** Google RT-X, Berkeley DROID, LeRobot, Physical Intelligence, Tesla
